作品 / Work

01 · 主项目 · 个人项目

《未竟之愿》

2D 像素类魂动作游戏 · Unity / C#

一款以防守驱动为核心的 2D 类魂横版动作游戏 demo。受到敌方攻击时按住防御进行普通格挡，把受到的伤害转成可回收的“虚血”；成功触发踩准时机的完美格挡、应对特殊攻击的识破，则在免伤的同时赎回虚血、积攒用于释放技能的体力、削减敌方韧性；配合进攻端的连段攻击持续削减韧性，最终把敌人破韧、处决击杀。

▶ 演示视频 📄 设计文档 (GDD) 💻 GitHub 源码

《THE LINGERING HOUR》

GMTK Game Jam(主题 COUNT DOWN)· 卡牌 · Unity / C# · 24h 制作
